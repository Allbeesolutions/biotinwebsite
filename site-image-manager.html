🖼️ Site Image Manager

Upload photos for your doctors, clinic, and homepage — get back a ready-to-upload copy of your website.

How this works: Your website is a static file with no server or database behind it, so there's no "log in and edit" admin panel possible. Instead, this tool runs entirely in your browser: load your current index.html, attach new photos, and it hands you back an updated site file + image folder to upload to your host — nothing is sent anywhere online. If you ever put this tool on a public web address, add a password to that folder on your host, since this page itself has no login.

⬇ Download updated site

Next steps:
1. Unzip the download — it contains index.html and an images folder with just the new photos you added.
2. Upload index.html so it replaces the old one.
3. Upload the new images folder so it merges into your existing images folder on the host (adding the new photos alongside the old ones) — don't delete your existing images folder first, since this download doesn't include your logo, favicons, or any doctor photo you didn't just upload.
4. Hard-refresh your site in the browser (photos are heavily cached, so it may take a moment to show).
